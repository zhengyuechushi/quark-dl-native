网络自检

这台主机能不能真的上网，取决于四件互相独立的事：域名解析、TCP、TLS 握手、证书校验。 点一次就知道断在哪一步。默认测的是 pan.quark.cn，也就是后面要拿网盘目录的那个域名。

结束运行

点了之后进程自己退出，不写任何标记文件，也不影响下次加载。这是主机界面那个「终止」按钮对 payload 做不到的事。重启用你原来的方式再加载一次 ELF 即可。

扫不了码？改用粘贴 Cookie

二维码是夸克官方登录页生成的，手机端扫不上时（网络、版本、摄像头）， 可以改从电脑浏览器取一次 Cookie，一样能登录。

先在电脑浏览器登录 pan.quark.cn，按 F12 打开开发者工具， 切到 Network，然后按 F5 刷新一次页面。在筛选框里打 clouddrive， 点其中一条 Status 是 200 的请求（名字多为 sort、member）。

办法一，最省事：右键那条请求 → Copy → Copy as cURL (bash)， 整段粘到上面。里面的 -H 'cookie: …' 会被自动揪出来，不用自己找。

办法二：在右侧 Headers 面板里找 Cookie: 那一行，复制冒号后面的值。 如果面板上写着「Provisional headers are shown」，说明这条请求根本没发出去（或来自缓存）， 上面就只有 Dnt、Referer 之类，没有 Cookie——换一条请求，或者直接用办法一。

办法三：Application（应用）→ Storage → Cookies → https://pan.quark.cn，把 __pus、__puus、__kp、 __kps、__uid 这些行按 名字=值; 名字=值 拼起来。 HttpOnly 的项在 Application 里照样能看到值，document.cookie 看不到，别在控制台里取。

cookie 存在 /data/quark-dl/cookie.txt（权限 600）。 它等同于登录凭证，别外传；不想留了在页面上点「退出登录」就会删掉。

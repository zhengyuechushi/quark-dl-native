网络自检

这台主机能不能真的上网，取决于四件互相独立的事：域名解析、TCP、TLS 握手、证书校验。 点一次就知道断在哪一步。默认测的是 pan.quark.cn，也就是后面要拿网盘目录的那个域名。

夸克账号

状态未登录

在电脑浏览器登录 pan.quark.cn，按 F12 → Network → 点任意一个请求 → 复制请求头里 Cookie: 那整行的值，粘到上面点登录。cookie 存在 /data/quark-dl/cookie.txt（权限 600）。它等同于登录凭证，别外传。

网盘

登录后这里会列出网盘根目录。

已选 0 项

勾目录会递归整个文件夹（最多 2000 个文件，分 50 个一批换直链）。文件下到上面那个保存目录。 这个页面只读网盘，不会移动、改名或删除任何东西。

下载

默认保存到 /data/homebrew，和 ProsperoStore 的安装目录一致。 文件先写成 .part，校验落盘后才改名，中断了重新加同一个链接会接着下。

控制

点了之后进程自己退出，不写任何标记文件，也不影响下次加载。这是主机界面那个「终止」按钮对 payload 做不到的事。重启用你原来的方式再加载一次 ELF 即可。
